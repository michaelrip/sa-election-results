Sources and reliability

This is an unofficial family dashboard. GitHub Actions checks publicly available ESP pages containing IEC-derived results every 15 minutes, and this page checks the imported snapshot every five minutes. This is not a direct IEC API feed or an official election declaration. Suburb and place labels are sourced from The Ledger SA's 2026 ward-area lists; these are geographic descriptions, not official IEC ward names. Missing results are shown as unavailable, not estimated. Voting districts reporting are not the same as ballots counted. Percentages are for the ward ballot; PR ballots and final council seats are different.
