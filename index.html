Sources and reliability

This is an unofficial family dashboard. GitHub Actions checks publicly available ESP pages containing IEC-derived results every 15 minutes, and this page checks the imported snapshot every five minutes. This is not a direct IEC API feed or an official election declaration. Suburb and place labels are sourced from The Ledger SA's 2026 ward-area lists; these are geographic descriptions, not official IEC ward names. Missing results are shown as unavailable, not estimated. Voting districts reporting are not the same as ballots counted. 2021 comparisons shown in brackets are historical ward-ballot percentages. Metro comparisons use completed 2021 results; 2026 ward comparisons use the voting districts matched to current ward boundaries and may omit new or split districts. A missing historical party share is not treated as zero. Vote counts are displayed only when sourced and validated, never derived from rounded percentages. The total shown is valid ward-ballot votes, not all ballots cast. Ward-level top-three party percentages and vote counts are imported only from the individual ESP ward-ballot pages when they match the metro result. If the source is unavailable or no longer matches, only the verified leader is shown. Percentages are for the ward ballot; PR ballots and final council seats are different.
